# UI interaction refinement

This release is a visual/interaction-only enhancement. Existing ERP business logic and APIs are unchanged.

## Updated
- Text, password, number, date, time, email, telephone fields and textareas
- Native selects with consistent cross-browser dropdown affordance
- Search fields and toolbar filters
- Primary, secondary and row-action buttons
- Modal overlays, headers, content, sticky action areas and mobile bottom-sheet behavior
- Data grids with stronger header hierarchy, alternating rows, hover/active states, record footer and scrollbars
- Dense editable marks/configuration grids
- Student/detail record surfaces
- Login form controls
- Responsive behavior for narrow screens

## Browser compatibility
CSS uses standard controls and layout behavior supported by current Chrome, Edge and Firefox. `backdrop-filter` is used only as progressive enhancement with a non-blur fallback.
