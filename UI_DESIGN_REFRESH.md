# VidyaOne UI Design Refresh

This refresh changes presentation only. Existing backend APIs and ERP workflows remain unchanged.

## Updated areas

- Premium two-panel login experience with role-aware portal label
- Modern VidyaOne branding and school-focused visual identity
- Responsive mobile login card
- Rich navy/blue sidebar with icon containers and active navigation state
- User avatar and live-workspace status treatment
- Sticky translucent top bar
- Redesigned dashboard hero panels
- Elevated KPI cards with clearer information hierarchy
- Modern table headers, hover states, spacing and surfaces
- Updated buttons, fields, selects, focus states and action toolbars
- Refined notifications, progress bars, cards, modals and document surfaces
- Better mobile behavior for navigation, dashboards and forms
- Cleaner print styling for downloadable/printable reports

## Design direction

The palette uses deep institutional navy for trust, a contemporary blue for product actions, and warm amber accents for the education brand. Surfaces are intentionally light and spacious so dense ERP information stays easy to scan.

No API contract or business workflow was intentionally changed as part of this refresh.
